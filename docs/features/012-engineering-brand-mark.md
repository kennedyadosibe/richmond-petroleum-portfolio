# Engineering Brand Mark

## What changed

The public homepage and profile-page brand links now use the original petroleum engineering illustration instead of the standalone `R` monogram.

## User experience

- The engineering visual is visible in the compact site header.
- The `RICH` and `PETROLEUM / STUDENT` labels remain readable.
- The brand link still returns visitors to the homepage.
- Decorative image markup is hidden from assistive technology because the link already has an accessible label.

## Validation

- TypeScript and Vite production build pass with `npm run build`.
