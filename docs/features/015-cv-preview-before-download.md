# CV Preview Before Download

## What changed

Added explicit CV preview links to Richmond's profile page. The preview opens the print-ready CV in a new browser tab, while separate download links remain available for visitors who want the file immediately.

## User experience

- The profile header includes a `View CV` link.
- The hero includes `View my CV` and `Download CV` actions.
- The CV opens in the browser so visitors can review it before saving or printing.

## Validation

- TypeScript and Vite production build pass with `npm run build`.
