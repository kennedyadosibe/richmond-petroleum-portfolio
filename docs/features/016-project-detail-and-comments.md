# Project Details and Comments

## What changed

Each project card now exposes both `View details` and `Comment` actions on its front face. Visitors no longer need to flip a card before commenting.

## User experience

- `View details` opens the selected project's description, category, status, tools, method, and outcome.
- `Comment` opens a form associated with the selected project.
- The technical flip remains available as an additional interactive way to inspect project methods and outcomes.
- Comments submitted through a project action retain that project's ID for moderation in the dashboard.

## Validation

- TypeScript and Vite production build pass with `npm run build`.
