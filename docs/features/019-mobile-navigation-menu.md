# Mobile Navigation Menu

## What changed

Added expandable mobile navigation menus to the public homepage and profile page.

## User experience

- The desktop navigation remains unchanged.
- On phones, a `Menu` control opens Work, About, and Notes links.
- The control changes to `Close` while the menu is open.
- Selecting a link closes the menu.
- The admin login icon remains available in the homepage mobile header.

## Validation

- TypeScript and Vite production build pass with `npm run build`.
