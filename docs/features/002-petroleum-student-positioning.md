# Feature 002: Petroleum Engineering Student Positioning

## Purpose

Align the portfolio with its actual owner: a petroleum engineering student rather than a software engineer or general engineering lab.

## User experience

- The site identifies the owner as a petroleum engineering student.
- The hero focuses on subsurface learning, reservoirs, wells, and field development.
- Project examples use petroleum engineering topics:
  - Well-log interpretation
  - Core analysis and fluid properties
  - Field development planning
- Project filters use Reservoir, Formation, and Production.
- Collaboration language invites field insight, academic feedback, and technical discussion.

## Implementation

- Updated project data and category labels in `src/main.ts`.
- Updated hero, approach, footer, and modal copy in `src/main.ts`.
- Kept the existing filtering, search, responsive layout, and feedback form behavior.

## Validation

- `npm run build` passes TypeScript checking and the Vite production build.
- Existing project filtering and feedback interaction patterns remain in place.
